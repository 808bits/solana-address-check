    A Solana address is the 32 byte public key itself, not a hash of it, so whether a private key can exist is a question about where those bytes land on edwards25519, answerable offline.

    Only in the prime-order subgroup can have a key. Off-curve and torsion addresses provably cannot: nothing times the base point ever reaches them. Small-order addresses are worse than useless, because anyone can forge a signature for one.
